
# Jellyfin Tag and Genre Manager Plugin
## Project Description:
The **Jellyfin Tag and Genre Manager** plugin is designed to manage custom tags and genres for media items in the Jellyfin media server. It allows users to create, edit, and apply tags/genres to their media content (movies, TV shows) via an easy-to-use UI.

### Issues Being Worked On:
- **Plugin Errors**: Missing references to `BasePlugin<>`, `Guid`, `IApplicationPaths`, `IXmlSerializer` while building the plugin.
- **Jellyfin Version**: The plugin is built for **Jellyfin 10.10.3**, but there are build issues related to missing assemblies or namespaces.
- **Plugin Class**: The `Plugin.cs` file is used to define the plugin and manage its configuration pages.

### Key Areas Needing Help:
- **Missing References**:
    - `BasePlugin<>`: Used to create the base plugin for Jellyfin, but Jellyfin’s plugin assembly is missing.
    - `Guid`: A .NET class that is not recognized, likely due to missing core .NET packages.
    - `IApplicationPaths`: Interface for accessing application paths, required for file storage and configuration.
    - `IXmlSerializer`: Jellyfin's XML serialization interface for handling configuration data.

- **.csproj File**:
    - Ensuring that all required **Jellyfin plugin dependencies** are properly referenced.
    - Ensuring the correct **target framework** (`net8.0`) is set for compatibility with Jellyfin 10.10.x.
